
# Atividade Avaliativa 01

## Implementação do GitHub na Unidade Curricular de Lógica de Programação

### Objetivo

Apresentar uma proposta de utilização do GitHub como ferramenta de apoio à aprendizagem durante uma Situação de Aprendizagem da UC de Lógica de Programação.

---

## Problema

A Cantina da Honestidade da escola não possui um sistema para controlar compras, estoque e saldo dos usuários.

Os estudantes deverão desenvolver uma solução utilizando algoritmos e organizar todo o projeto através do GitHub.

---

## Recursos do GitHub

- README
- Issues
- Projects (Kanban)
- Pull Requests
- Commits
- Wiki

---

## Competências Desenvolvidas

- Lógica de programação
- Trabalho em equipe
- Documentação
- Organização de projetos
- Versionamento
- Colaboração

- ---


- Quantidade em estoque

### Regras

- O código deve ser único.
- O valor deve ser maior que zero.
- A quantidade inicial deve ser maior ou igual a zero.
